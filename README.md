# 📶 WiFi Hacker Demo

Interactive WiFi Hacker demo with hacker-style UI.

## Features
- ✨ Glowing animations
- 📡 Network scanning effect
- 🔐 Password cracking demo
- 📱 Mobile responsive

## Files
- `index.html` - Main interface
- `styles.css` - Styling and animations  
- `script.js` - Interactive demo logic

## How to Run

Open `index.html` in your browser and click "Start Hack" button!
